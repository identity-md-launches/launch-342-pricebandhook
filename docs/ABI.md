# Delivered ABIs

- [Band.json](abi/Band.json) — `src/Band.sol:Band`
- [PriceBandHook.json](abi/PriceBandHook.json) — `src/PriceBandHook.sol:PriceBandHook`

These are standard JSON ABI arrays generated by `python3 scripts/export-abi.py` from the pinned
compiler configuration. Regenerate them after any source or compiler change. They contain constructor,
function, event and custom-error definitions including inherited entries; inherited disabled callback
entries do not imply that their permissions are enabled.

## Band

The constructor has no arguments and is nonpayable. Standard ERC-20 reads are `name()`, `symbol()`,
`decimals()`, `totalSupply()`, `balanceOf(address)` and `allowance(address,address)`. Writes are
`transfer(address,uint256)`, `approve(address,uint256)` and `transferFrom(address,address,uint256)`;
they return `bool` and revert for invalid addresses, insufficient balances or allowances. Infinite
allowance (`uint256.max`) is not decremented. `Transfer` and `Approval` follow the vendored
OpenZeppelin implementation; `transferFrom` does not emit an `Approval` event for allowance spending.
Values are unsigned integers in 18-decimal base units. There is no payable receiver or fallback.

## PriceBandHook

| API | Meaning |
| --- | --- |
| `constructor(address poolManager_)` | The ABI encoding of the single `IPoolManager` argument; validates hook address permission bits. |
| `poolManager() -> address` | Immutable manager, trusted to authenticate pool lifecycle and return slot0. |
| `getHookPermissions() -> tuple` | Fourteen named booleans in v4 order. Only `afterInitialize` and `afterSwap` are true. |
| `band(bytes32 poolId) -> (bool active, int24 avgTick, int24 lower, int24 upper, uint256 hour)` | Preview exactly the next swap's band at this block timestamp. |
| `lastTick(bytes32 poolId) -> int24` | Last successful swap tick, or initialization tick if no swap. Unknown pool returns zero. |
| `LOWER_OFFSET() -> int24` | `2231`. |
| `UPPER_OFFSET() -> int24` | `1823`. |

`PoolId` is ABI-encoded as `bytes32`; `IPoolManager`, `IHooks` and `Currency` are encoded as addresses.
`avgTick`, `lower` and `upper` must be decoded as signed integers. `hour` is a UTC hour index, not a
timestamp. When active it is `floor(block.timestamp / 3600) - 1`; when inactive, all four numeric
outputs are zero. Inactive covers both an unknown pool and an initialized pool whose first hour
boundary has not passed. `lastTick == 0` alone is not proof of pool initialization.

### PoolManager callbacks

`afterInitialize(address sender, PoolKey key, uint160 sqrtPriceX96, int24 tick)` records initialization
and returns `IHooks.afterInitialize.selector`. `afterSwap(address sender, PoolKey key, SwapParams params,
int256 delta, bytes hookData)` updates and checks the hour band, returning
`(IHooks.afterSwap.selector, int128(0))`. The `BalanceDelta` Solidity type is represented as `int256`
in the ABI. Only the immutable PoolManager can invoke either callback; users invoke the router.

`PoolKey` has `(address currency0, address currency1, uint24 fee, int24 tickSpacing, address hooks)`.
`SwapParams` has `(bool zeroForOne, int256 amountSpecified, uint160 sqrtPriceLimitX96)`. No callback
uses the untrusted hookData or router sender to authorize or credit an end user.

### Events and failures

`HourClosed(bytes32 indexed poolId, uint256 hour, int24 avgTick)` is emitted once for the latest
closed hour on the first successful swap that advances across one or more boundaries. Reverted
swaps emit no committed event and make no committed state changes. No event is emitted for reads,
idle time alone, initialization, or another swap within the same hour.

`PriceOutOfBand(int24 tick, int24 lower, int24 upper)` reports the rejected **post-swap tick** and
the enforced edges. It occurs only if that tick is outside and its distance to the band has not
strictly decreased. Through PoolManager, core wraps this error in
`WrappedError(address target, bytes4 selector, bytes reason, bytes details)` with the hook address,
`afterSwap` selector, encoded `PriceOutOfBand` reason and `HookCallFailed` selector in `details`.

`NotPoolManager()` protects all callbacks. `HookNotImplemented()` is the inherited response for
disabled callbacks invoked by the manager. `PoolNotInitialized(bytes32)` rejects an afterSwap without
initialized hook state (a genuine PoolManager already prevents swapping uninitialized pools).
`HookAddressNotValid(address)` rejects construction at an address with mismatched permission bits.

The contract has no payable receiver, fallback, fees, claim tokens, owner setters or upgrades.
